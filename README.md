# OpenMinis Repository

## Overview

OpenMinis is the central ecosystem platform that orchestrates the AI Real Estate experience. It integrates the strategic vision, architecture, roadmap, and governance framework into a unified operational system. Built on Alpine Linux with a fully functional iSH shell, OpenMinis serves as the backbone for all AI-powered real estate operations across the Florida tech corridor.

## Core Components

- **MINIS-ARCHITECTURE.md** – Detailed ecosystem architecture and board structure
- **STRATEGIC-KNOWLEDGE-BASE.md** – Synthesized visions and strategic knowledge
- **IMPLEMENTATION-ROADMAP.md** – 12-month phased implementation plan
- **GRANT-APPLICATION-TRACKER.md** – Grant application management and tracking
