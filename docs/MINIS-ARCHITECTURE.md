# OpenMinis AI Ecosystem Architecture

## Core Philosophy
Minis is the platform; Agent Mini is the orchestrator layer built on it. This repository serves as the central development hub for the Minis AI ecosystem, enabling specialized sub-agents with niche expertise and thought leadership.

## Board Structure (From Chat Strategic Framework)

### Executive Leadership
- **Chairperson (You)** — Vision, strategy alignment, final decision-maker
- **CFO** — Wealth architecture, capital raising
- **COO** — Execution optimization, process design
- **CMO** — Story architecture, brand positioning
- **CTO** — AI architecture, system design
- **CRO** — Community architecture, network effects
- **CSO** — Strategic assessment, gap identification

### Sub-Agent Personalities
Each sub-agent operates with a specific persona, expertise, and mandate to challenge assumptions and propose innovations.

## Technology Stack
- **Primary Environment:** iSH Linux (Alpine Linux, aarch64)
- **Shell:** BusyBox ash (with bash fallbacks)
- **Package Management:** apk add (Alpine packages)
- **Python:** Data analysis packages via apk (numpy, pandas, matplotlib via py3-*)
- **AI/ML:** Stability AI, OpenAI APIs, Abacus AI platform

## Key Integrations
- **REAL Brokerage API** — 85/15 commission splits, AI Referral Center
- **Consider It Closed** — Transaction coordination system
- **Abacus AI** — Workflow automation and predictive analytics
- **EXO Framework** — Intelligence Stack (PURPOSE→SENSE→INTERPRET→DECIDE→ORCHESTRATE→LEARN)
- **Google AI** — Gemini, Imagen for art generation
- **OpenAI** — ChatGPT, DALL-E for content creation

## Development Guidelines
- **Keep it concise** — Context window is public good
- **Prefer concise examples** over verbose explanations
- **Match freedom degree** to task fragility
- **Progressive disclosure** — Load metadata first, then body, then resources
- **Never include** extraneous files (README, INSTALL, CHANGELOG)
